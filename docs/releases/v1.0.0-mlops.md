# v1.0.0-mlops: corrected evaluation and MLOps layer

`main` after PR #1 (MLOps layer), PR #2 (release instructions) and PR #3 (security review,
MovieTweetings evaluation). Acceptance evidence: `FINAL_E2E_ACCEPTANCE.md`.

## Fixed
- **Test-set leakage in model selection**: `src/main.py` and `src/run_ml1m.py` chose the SVD
  rank on the test set and reported that same test score. Now: per-user train / validation /
  test split (70/10/20, zero shared pairs), rank chosen on validation only, test evaluated once.
  Historical results are preserved and labelled in `outputs/HISTORICAL_RESULTS.md`.
- `train_test_split` crashed under pandas 3 (8 of the original 48 tests failed).
- Dataset download failed TLS verification (GroupLens omits its intermediate certificate);
  the public intermediate is shipped and the archive SHA-256 is verified.
- README claimed "cross-validation" (none was performed); weak test assertions strengthened.

## Added
FastAPI service (recommendations, rating prediction, feedback, metrics, monitoring summary),
versioned model registry with explicit approval and rollback, MLflow tracking (local SQLite),
Prometheus metrics with PSI drift checks and delayed-label performance, gated retraining,
Docker images + compose, GitHub Actions CI (lint, tests on 3.12/3.13, Docker smoke test,
real-data pipeline), ranking metrics and a most-popular baseline, full documentation.

## Security review (SECURITY.md)
Fixed: constant-time admin-token check; no unsalted/placeholder-salted user pseudonyms;
registry versions readable by the serving user; API code not writable at runtime; base-image
pip/setuptools advisories (images audit clean). Compose publishes API and MLflow on 127.0.0.1,
drops all capabilities, sets no-new-privileges and mounts the registry read-only.
Still required for production: TLS, authentication/authorisation, rate limiting at a gateway.

## Alternative dataset
Separate MovieTweetings pipeline (MIT-licensed by its author; legal review required):
k = 5 (validation), test RMSE 0.6930 vs 0.6986 bias baseline (0.5-5 scale); most popular
NDCG@10 0.0568 vs SVD 0.0039. `docs/MOVIETWEETINGS_EVALUATION.md`, `docs/DATASET_LICENSING.md`.

## Results (MovieLens latest-small, test evaluated once)
SVD k = 20 (validation-selected): test RMSE 0.8853, MAE 0.6754 (best bias baseline 0.8943).
Reproduced on GitHub Actions from a fresh download. MovieLens 1M: test RMSE 0.9013.

## Known limitations (read before use)
- **Licence: MovieLens is for research use only. Commercial or revenue-bearing use requires
  written permission from GroupLens (the University of Minnesota offers a negotiated licence),
  or replacement with a commercially licensed / client-owned dataset.** No such permission is held.
- Retraining gate is permissive (minimum improvement 0.0, automatic promotion): a noise-trained
  candidate was promoted on MovieTweetings. Set a stricter policy before production.
- For top-10 recommendation a most-popular list is far better offline
  (NDCG@10 0.147 vs 0.011 for SVD); the model's strength is rating prediction.
- Random per-user split (not temporal); popularity-only cold start.
- Retraining was demonstrated with synthetic feedback only.
- No API authentication, TLS, rate limiting or cloud deployment; not production-ready.
