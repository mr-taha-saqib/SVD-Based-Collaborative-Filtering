## 1. Project source code

the delivered code, report (`report/`) and slides (`presentation/`) are governed by the agreement
between the client and the developer (the Fiverr order terms). If a specific licence is wanted,
the copyright holder should add a `LICENSE` file; none has been assumed here.

## 3. Bundled certificate

`certs/incommon-ovg2c-intermediate.pem` is a **public** intermediate CA certificate
(subject *InCommon Intermediate CA - OVG2C*, Internet2; issuer *emSign Root TLS CA - G1*; valid until
2029-04-07), shipped because GroupLens does not send it, so the dataset download can be
TLS-verified. It contains no private key.
